# 03 · 数据库设计

## 1. 选型与策略

- **数据库**：SQLite（`modernc.org/sqlite` 纯 Go 驱动，免 CGO）。
- **迁移策略**：自研轻量迁移执行器（`internal/store/db.go`）：
  - 内嵌迁移列表（`[]migration{version, name, sql}`），SQL 同时以文件形式保留在 `sql/migrations/` 供人工审查；
  - `schema_migrations` 表记录已应用版本，启动时按版本号升序、逐条在事务中执行；
  - 同时设置 SQLite `PRAGMA user_version` 作为冗余版本标记；
  - 迁移只增不改，新增字段走新迁移。
- **时间格式**：统一存储 UTC，`TEXT`（RFC3339）。
- **软删除**：`certificates.deleted_at` 置位；其余表硬删除（受审计保护）。
- **外键**：开启 `PRAGMA foreign_keys=ON`；业务层负责一致性，仅通知去重用唯一索引约束。

## 2. ER 关系总览

```
certificates 1 ──── * renewals
certificates 1 ──── * deployments        （经 renewal 关联，冗余 cert_id 便于查询）
deployment_targets 1 ──── * deployments
certificates 1 ──── * notifications
notification_rules * ────（匹配）certificates（按 environment/event_type 匹配，非外键）
audit_logs（独立，resource_type+resource_id 指向任意资源）
```

## 4. 迁移清单（规划 6 个版本）

| 版本 | 名称 | 内容 |
|------|------|------|
| 1 | init_schema | 建 certificates、deployment_targets、renewals、deployments |
| 2 | notifications | 建 notifications + 去重唯一索引 |
| 3 | notification_rules | 建 notification_rules |
| 4 | audit_logs | 建 audit_logs + 索引 |
| 5 | schema_migrations_meta | 建 schema_migrations 表（引导迁移自身） |
| 6 | seed_demo_target | 插入默认部署目标（localhost:8443, static 方法）与默认通知规则 |

> 说明：v5 用于从零初始化；实际执行器会在首次运行时先建 `schema_migrations` 再应用 1–4。v6 提供演示数据，便于端到端验证。

`sql/migrations/` 下对应存放 `001_init_schema.sql` … `006_seed_demo_target.sql`（内容与内嵌迁移一致）。

## 5. 典型查询

- 到期检查：`SELECT * FROM certificates WHERE deleted_at IS NULL`（全量扫描，量小足够）；
- 即将到期告警：`WHERE deleted_at IS NULL AND status='expiring_soon' AND last_checked_at < now-1h`；
- 自动续期候选：`WHERE deleted_at IS NULL AND auto_renew=1 AND days_to_expire <= renew_threshold_days AND id NOT IN (SELECT certificate_id FROM renewals WHERE status IN ('pending','issuing','issued','deploying','verifying'))`；
- 通知去重：`INSERT OR IGNORE INTO notifications(certificate_id,event_type,...) VALUES(...)`，检查 `RowsAffected`；
- 仪表盘统计：`GROUP BY status`、`COUNT`、`SUM(CASE...)` 组合。

## 6. 一致性说明

- 写操作集中在 store 层，service 层通过 `WithTx` 包装多表写入（如"创建续期 + 审计日志"）；
- 通知去重依赖唯一索引，业务层不做先查后插（避免竞态）；
- 软删除证书：其续期/部署/通知记录保留，供历史查询，但列表默认过滤 `deleted_at IS NOT NULL`。
