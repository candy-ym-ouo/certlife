# 09 · 实施计划

> 面向"先生成文档、后实现代码"的推进方式。本计划描述实现阶段的阶段划分、交付物与每阶段验证方式。

## 0. 前置：文档基线（已完成）

交付物：README + docs/01–09。文档冻结后，实现严格按文档执行；文档与代码不一致时以文档为准修订代码。

## 1. 阶段划分

### 阶段一：骨架与配置（0.5 天）

**交付物**：
- `go.mod`（module `certlife`，Go 1.22+，依赖 `modernc.org/sqlite`）
- `cmd/certlife/main.go`（70 行预算）
- `internal/config/config.go`（90 行预算）
- `config.yaml` 示例、`Makefile`

**验证**：`go build ./...`；`./bin/certlife -h` 打印配置帮助；`go vet ./...` 通过。

### 阶段二：模型层（0.5 天）

**交付物**：`internal/model/` 5 个文件（290 行预算）+ `model_test.go`
**验证**：`go test ./internal/model/ -cover` ≥ 90%；`gofmt -l .` 无输出。

### 阶段三：持久化层（1 天）

**交付物**：`internal/store/` 5 个文件（465 行预算）+ `sql/migrations/001–006` + `store_test.go`
**验证**：迁移幂等测试通过；各仓储 CRUD/过滤/分页/去重索引测试通过。

### 阶段四：业务逻辑层（1.5 天）

**交付物**：`internal/service/` 5 个文件（460 行预算）+ 3 个 service 测试文件
**验证**：状态机全链路测试（签发→部署→验证→完成/失败）、幂等测试、去重重试测试通过。

### 阶段五：后台任务（1 天）

**交付物**：`internal/task/scheduler.go` + `jobs.go`（265 行预算）+ `scheduler_test.go`
**验证**：TriggerNow、防重入、优雅停止测试通过；手动触发 5 个任务均返回正确 detail。

### 阶段六：API 层（1 天）

**交付物**：`internal/api/` 5 个文件（460 行预算）+ `api_test.go`
**验证**：httptest 全端点测试（401/400/404/409/201/202/204）通过。

### 阶段七：TLS 工具与前端（0.5 天）

**交付物**：
- `internal/tlsutil/check.go`（75 行预算）+ `check_test.go`
- `web/index.html` / `web/app.js` / `web/style.css`（约 480 行，非 Go）
- `scripts/fake_target/main.go`（自签 TLS 测试目标）

**验证**：`check_test.go` 通过；浏览器访问 `http://127.0.0.1:8080/web/` 可完成「登记证书 → 详情 → 续期」操作。

### 阶段八：端到端验证与约束收口（0.5–1 天）

**交付物**：`scripts/verify.sh`、`scripts/count_lines.sh`
**验证**：
1. `bash scripts/verify.sh` 全绿（登记→到期检查→续期→部署验证→通知→审计 全链路）；
2. `bash scripts/count_lines.sh` 断言 2000 < 行数 < 2200、20 < 文件数 < 25；
3. `go vet ./...`、`gofmt -l .`、`go test ./...` 全部通过；
4. 若行数越界：超上限 → 精简注释/合并辅助函数；低于下限 → 补充文档注释与边界工具函数，然后重跑校验。

## 2. 里程碑与验收标准

| 里程碑 | 标准 |
|--------|------|
| M1 可运行 | 服务启动、迁移自动执行、health 返回 up |
| M2 核心闭环 | 登记→到期检查→续期→部署验证→通知 全链路可手动驱动（API + 前端） |
| M3 约束达标 | 行数 ∈ (2000, 2200)、文件数 ∈ (20, 25)、测试全绿、verify.sh 全绿 |

## 3. 风险与对策

| 风险 | 对策 |
|------|------|
| 行数超上限 | 预算留 25 行缓冲；handler 瘦身原则；阶段八收口时压缩注释与辅助函数 |
| 行数不足 | 预算距下限 175 行；补包注释、状态机说明注释、边界工具函数（如 JSON 序列化辅助、时间格式化） |
| 文件数越界 | 预算 24 文件（区间中部）；任何拆分/合并必须重算并更新本文档 |
| SQLite 并发写锁 | 单写路径 + 任务防重入；写操作短事务；文档已注明 |
| 真实 TLS 验证环境依赖 | `scripts/fake_target` 本地自签服务提供确定性验证目标 |

## 4. 实现顺序依赖图

```
web（可与 api 并行）        scripts（最后收口）
```
