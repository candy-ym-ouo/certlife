# 06 · 前端设计（简单界面）

## 1. 定位与原则

- **简单**：原生 HTML + CSS + 原生 JS（fetch 调 API），零构建、零依赖、无 npm；
- 由 Go `embed` 编译进二进制，`/web/*` 直接访问，无需额外静态服务器；
- 单页应用（SPA）+ 轻量 hash 路由（`#/certs`、`#/cert/:id` …），刷新不丢失位置；
- 所有数据通过 `/api/v1/*` 获取，前端只做展示与表单收集，不做业务判断。

## 2. 文件与规模

| 文件 | 职责 | 预估行数 |
|------|------|----------|
| `web/index.html` | 页面骨架、导航、各视图容器、表单模板 | ~130 |
| `web/app.js` | 路由、API 封装、视图渲染、事件绑定 | ~260 |
| `web/style.css` | 极简样式（卡片、表格、状态徽章、表单） | ~90 |

> 前端不计入 Go 代码行数约束（约束仅针对 `*.go` 且排除 `*_test.go`）。

## 3. 页面结构

```
┌──────────────────────────────────────────────────────────┐
│ CertLife · 证书生命周期服务              [状态徽章] 刷新  │
├──────────┬───────────────────────────────────────────────┤
│ 导航      │  内容区（视图容器）                            │
│ ▸ 仪表盘  │                                              │
│ ▸ 证书    │                                              │
│ ▸ 续期    │                                              │
│ ▸ 部署    │                                              │
│ ▸ 通知    │                                              │
│ ▸ 任务    │                                              │
│ ▸ 审计    │                                              │
└──────────┴───────────────────────────────────────────────┘
```

Hash 路由：
- `#/` 仪表盘
- `#/certs` 证书列表（含"登记证书"表单）
- `#/cert/:id` 证书详情（元信息 + 续期历史 + 部署记录 + 通知记录 + 操作按钮）
- `#/renewals` 续期列表（按状态过滤，含"重试"按钮）
- `#/deployments` 部署记录列表（含 verification 摘要）
- `#/notifications` 通知记录（含规则管理 Tab）
- `#/targets` 部署目标管理
- `#/tasks` 任务列表 + 手动触发按钮
- `#/audit` 审计日志

## 4. 各视图说明

### 4.1 仪表盘（`#/`）

- 统计卡片：证书总数 / valid / expiring_soon / expired；近 30 天到期数；续期成功率；今日通知成功/失败；
- "7 天内到期"表格（名称、域名、剩余天数、状态徽章、跳转详情）；
- 数据源：`GET /api/v1/stats`、`GET /api/v1/certificates?status=expiring_soon`。

### 4.2 证书列表（`#/certs`）

- 顶部：关键字搜索框、状态/环境/标签筛选、分页控件；
- 表格列：名称、域名、签发者、有效期、剩余天数、状态徽章、环境、自动续期、操作（详情/续期/删除）；
- 右上"登记证书"按钮展开表单（字段见 3.2 节），提交 `POST /api/v1/certificates`；
- 状态徽章配色：valid 绿、expiring_soon 橙、expired 红。

### 4.3 证书详情（`#/cert/:id`）

- 元信息卡片：全部登记字段 + `days_to_expire` + `last_checked_at`；
- 操作：立即续期（`POST .../renew`，force 可选）、编辑、删除；
- Tab：
  - 续期历史（表格 + 状态机步骤展示）；
  - 部署记录（每目标一行：状态、验证结果 JSON 摘要、回滚标记）；
  - 通知记录（事件类型、通道、状态、重试次数）。

### 4.4 续期（`#/renewals`）

- 按状态过滤（进行中/completed/failed）；
- failed 行提供"重试"（`POST /api/v1/renewals/{id}/retry`）。

### 4.5 部署（`#/deployments`）

- 部署记录列表；verification 字段渲染为"握手/序列号/SAN/有效期"勾选视图。

### 4.6 通知（`#/notifications`）

- Tab1 通知记录：事件、通道、收件人、状态、时间；
- Tab2 规则管理：规则 CRUD 表单（事件多选、环境多选、通道多选、收件人/回调 URL）。

### 4.7 任务（`#/tasks`）

- 任务表：名称、间隔、上次执行时间、结果、累计次数；
- 每行"立即执行"按钮 → `POST /api/v1/tasks/run`，展示返回 detail。

### 4.8 审计（`#/audit`）

- 分页表格：时间、操作者、动作、资源、摘要；支持按 action 过滤。

## 5. 交互细节

- `app.js` 提供 `api(method, path, body)` 封装：自动带 `X-API-Key`（存于 `localStorage`，首屏提示输入，默认 `dev-key`）、解析统一响应、401 时提示；
- 表单提交成功后 toast 提示并刷新列表；错误码映射为中文提示（409 → "已有进行中的续期"等）；
- 全页右上角"刷新"按钮重新拉取当前视图数据；仪表盘每 30s 自动刷新（仅该页）；
- 时间显示：RFC3339 转为本地时间 `YYYY-MM-DD HH:mm`；剩余天数负值显示"已过期 N 天"。

## 6. 静态资源服务（Go 侧）

```go
//go:embed ../../web
var webFS embed.FS

// router.go 中：
mux.Handle("/web/", http.StripPrefix("/web/", http.FileServer(http.FS(subFS))))
mux.HandleFunc("/", func(w, r){ http.Redirect(w, r, "/web/", 302) })
```

- `auth` 中间件放行 `/web/*` 与 `/api/v1/health`；
- 前端无缓存问题：`Cache-Control: no-cache` 头由 FileServer 默认行为覆盖即可（MVP 不加版本号）。
